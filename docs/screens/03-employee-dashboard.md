# Screen 03 — Employee Dashboard

**Route:** `/employee/dashboard`  
**Design ref:** `stitch_consultancy_operations_hub/employee_dashboard_expert_partner/`  
**Skill:** `skills/06-employee-dashboard.md`

## Layout
Employee shell. Two-column: Time & Attendance (60%) + Profile (40%). Weekly Hours card below left column.

## Time & Attendance Card
- Current date + live time (updates every second)
- Status dot: grey (off duty) / green (on duty)
- Button: "→ Clock In" / "Clock Out" depending on state

## Weekly Hours Card
- Large number (e.g., 32.0) / 40h target
- Black progress bar
- "80% of weekly goal reached · 8h remaining"

## Profile Card
- Avatar with ✏ Edit overlay
- Name, Role, Employee ID, Joined Date, Base Office
- "View Full Profile →" button
